## Overview

MA6_Debt is a comprehensive financial management system designed to enforce discipline and integrity in cash handling.

### Tech Stack

- **Frontend**: Next.js 15 (Feature-Based Architecture)
- **Backend**: ASP.NET Core 9 (Clean Architecture)
- **Database**: PostgreSQL
- **ORM**: Entity Framework Core

## Key Features

- **Multi-level Wallets**: Parent/Child wallet structure for sophisticated fund tracking.
- **Double-entry Transactions**: Every transaction has a source and destination to ensure balanced books.
- **Debt Management**: Tracking receivables and payables with `DebtPartners`.
